Decode VP9 video (WebM) using the <canvas> tag

Same VP9/WebM source as the video tag version demo above, but rendered directly to a <canvas> instead of being re-encoded to MP4.

Code snippet

<canvas is="universal-canvas_1" data-url="https://dl6.webmfiles.org/elephants-dream.webm" using="solver_1"
     with="libvpx_1;webmdmx_1"> </canvas>
