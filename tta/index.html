Play True Audio (TTA) using the <audio> tag

True Audio is a lossless codec with its own container, built around adaptive prediction and Rice coding. Decoded by libtta_1. Being lossless, the check is the strongest possible: not one sample of 882 000 differs from the audio that was encoded.

Code snippet

<audio is="universal-audio_1" src="testcard.tta" using="solver_minimal_1"
        with="libtta_1" controls> </audio>

Specifications :

The specifications of the test sequence are :

Format TTA lossless, 44.1 kHz stereo, 10 s
FileSize 406 Ko
Solver solver_minimal_1
