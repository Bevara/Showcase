Play Ogg Vorbis audio using the <audio> tag

This demo demuxes an Ogg container with ogg_1 and decodes the Vorbis audio stream inside it with vorbis_1.

Code snippet

<audio is="universal-audio_1" src="Median_test.ogg" using="solver_minimal_1"
        with="ogg_1;vorbis_1" controls> </audio>

Specifications :

The specifications of the test sequence are :

Format Ogg (Vorbis)
FileSize 734 Ko
Solver solver_minimal_1
