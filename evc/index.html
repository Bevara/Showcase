Decode MPEG-5 EVC video using the <video> tag

MPEG-5 EVC (Essential Video Coding) was standardised as a royalty-friendly alternative to HEVC. Its elementary stream is not delimited by start codes: each NAL unit is prefixed by its own 4-byte length. libxevd_1 decodes it — on top of xevd, the reference decoder — and libx264_1 with isobmff_1 produce the MP4. All 50 frames come out, matching a natively built xevd to ~61 dB PSNR.

Code snippet

<video is="universal-video_1" src="testcard.evc" using="solver_1"
        with="libxevd_1;isobmff_1;libx264_1" controls> </video>

Specifications :

The specifications of the test sequence are :

Format EVC raw elementary stream, 320x180, 25 fps, 50 frames
FileSize 7.4 Ko
Solver solver_1
