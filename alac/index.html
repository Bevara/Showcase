Play Apple Lossless (ALAC) audio using the <audio> tag

ALAC is Apple's lossless codec, carried in an MP4/M4A container. This demo shows a two-filter chain: isobmff_1 demuxes the M4A and hands the ALAC packets to libalac_1, which decodes them — the decoder never sees the container. Being lossless, the output was checked against the audio that was encoded: not one sample of 882 000 differs.

Code snippet

<audio is="universal-audio_1" src="testcard.m4a" using="solver_1"
        with="isobmff_1;libalac_1" controls> </audio>

Specifications :

The specifications of the test sequence are :

Format ALAC lossless in M4A, 44.1 kHz stereo, 10 s
FileSize 476 Ko
