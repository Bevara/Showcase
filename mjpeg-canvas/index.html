Decode Motion JPEG video using the <canvas> tag

The same Motion JPEG frames as the video tag version, this time in a QuickTime container and drawn directly to a <canvas>. Rendering to a canvas shortens the chain: there is no MP4 to produce, so neither the colour conversion nor the H.264 encoder is needed — isobmff_1 demultiplexes the file and libjpeg_1 expands each frame straight into the compositor.

Code snippet

<canvas is="universal-canvas_1" data-url="testcard.mov" using="solver_1"
     with="isobmff_1;libjpeg_1"> </canvas>
