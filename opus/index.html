Play Opus audio using the <audio> tag

Opus is a modern, low-latency codec widely used for real-time communication. This demo demuxes the Ogg container with ogg_1 and decodes the Opus stream with libopus_1.

Code snippet

<audio is="universal-audio_1" src="ff-16b-1c-44100hz.opus" using="solver_minimal_1"
        with="ogg_1;libopus_1" controls> </audio>

Specifications :

The specifications of the test sequence are :

Format Ogg (Opus)
FileSize 1.6 Mo
Solver solver_minimal_1
