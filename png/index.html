Display PNG images using the <img> tag

PNG is decoded natively by every browser already. This demo runs it through the same WebAssembly filter pipeline used for the less common formats on this page, using the exact minimal-footprint solver (solver_minimal_1) the project ships for production embeds — useful as a size/behaviour baseline, and because the same libpng_1 filter is reused as the re-encoding step by other demos (JPEG below, for instance).

Code snippet

<img is="universal-img_1" src="Freedom.png" using="solver_minimal_1"
     with="libpng_1"> </img>

Specifications :

The specifications of the test sequence are :

Format PNG
FileSize 350 Ko
Solver solver_minimal_1
