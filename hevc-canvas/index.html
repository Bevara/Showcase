Decode HEVC video (MP4) using the <canvas> tag

Same HEVC/MP4 source as the video tag version demo above, but rendered directly to a <canvas> instead of being re-encoded.

This particular source (720p, video-only, 32MB) did not produce a visible frame within our test window on the canvas path, unlike the AV1/VP9/MPEG-2 canvas demos which all render promptly — likely a slow first-decode on this larger file rather than a hard failure, but treat this one as unverified.

Code snippet

<canvas is="universal-canvas_1" data-url="hevcds_720p30_2M.mp4" using="solver_1"
     with="libde265_1;libfaad_1;isobmff_1"> </canvas>
