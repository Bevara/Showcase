Decode AVS2 video using the <video> tag

AVS2 (AVS2-P2) is the Chinese national standard that preceded AVS3. The signal is a raw elementary stream, with no container: libdavs2_1 splits it on the picture and sequence start codes and emits one raw frame per picture, which libx264_1 and isobmff_1 then turn into the MP4 the <video> element plays. All 50 frames come out, and match a natively built davs2 to ~58 dB PSNR.

Code snippet

<video is="universal-video_1" src="testcard.avs2" using="solver_1"
        with="libdavs2_1;isobmff_1;libx264_1" controls> </video>

Specifications :

The specifications of the test sequence are :

Format AVS2 raw elementary stream, 320x180, 25 fps, 50 frames
FileSize 18 Ko
Solver solver_1
