Render a VRML97 scene into a <canvas>

VRML97 (ISO/IEC 14772) is the 3D scene language the web had before WebGL, and MPEG-4 BIFS grew out of it - the node set is largely shared. The same loader reads it: btplay_1 parses the classic .wrl syntax into the compositor's scene graph, which renders it in 3D through WebGL. Note that the scene avoids Text nodes: this build carries no font, and a text node makes the compositor divide by zero.

Code snippet

<canvas is="universal-canvas_1" data-url="scene2.wrl" using="solver_1"
        with="btplay_1" interactive> </canvas>
