Play Speex audio using the <audio> tag

Speex is the CELP-based speech codec Xiph published before Opus superseded it, still met in voice recordings and VoIP archives. This demo shows a two-filter chain: ogg_1 demuxes the Ogg container and hands the Speex packets to libspeex_1, which decodes them — the decoder never sees the container.

Code snippet

<audio is="universal-audio_1" src="testcard_wb.spx" using="solver_minimal_1"
        with="ogg_1;libspeex_1" controls> </audio>

Specifications :

The specifications of the test sequence are :

Format Speex wideband (sub-band CELP), 16 kHz mono, 10 s
FileSize 35 Ko
Solver solver_minimal_1
