Display QOI images using the <img> tag

QOI (“Quite OK Image”) is a modern, deliberately simple lossless format designed to encode and decode much faster than PNG at a comparable size. Decoded here with libqoi_1

Code snippet

<img is="universal-img_1" src="kodim23.qoi" using="solver_minimal_1"
     with="libqoi_1"> </img>
