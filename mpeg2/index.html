Decode MPEG-2 video using the <video> tag

MPEG-2 is the video codec behind DVDs and digital broadcast TV. This demo decodes a raw MPEG-2 elementary stream with libmpeg2_1.

Code snippet

<video is="universal-video_1" src="centaur_1.mpg" using="solver_1" with="libmpeg2_1;isobmff_1;libx264_1" controls> </video>

Specifications :

The specifications of the test sequence are :

Format MPEG-2 (raw ES)
FileSize 550 Ko
Solver solver_1
