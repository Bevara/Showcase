Decode MPEG-2 video using the <video> tag

MPEG-2 is the video codec behind DVDs and digital broadcast TV. This demo decodes a raw MPEG-2 elementary stream with libmpeg2_1.

This pipeline re-encodes the decoded frames to MP4 through an H.264 encoder filter (ffmpeg-x264_1), matching exactly how this decoder is exercised in the project's own automated test suite. That encoder negotiation step is not fully reliable in every browser/GPAC build combination yet, so playback may not render everywhere — this demo still exercises the full demux + decode chain end to end.

Code snippet

<video is="universal-video_1" src="centaur_1.mpg" using="solver_minimal_1"
     with="libmpeg2_1;isobmff_1;ffmpeg-x264_1" controls> </video>
