Decode Ogg/Theora video using the <video> tag

This demo shows how an Ogg/Theora video can be played back in modern browsers using a WebAssembly-based filter pipeline.

Although this format was once promoted as an open video standard, most major browsers (including Chrome, Firefox and Safari) no longer support it natively.

Code snippet

We decode the Ogg file trailer_1080p.ogg, which contains a Theora video stream and a Vorbis audio stream, using the universal video tag:

<video is="universal-video_1" src="trailer_1080p.ogg" using="solver_1" with="ogg_1;vorbis_1;theora_1;libx264_1;isobmff_1" controls> </video>
