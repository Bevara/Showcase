Display AVIF images using the <img> tag

AVIF (.avif) stores an image using the AV1 video codec's intra-frame compression. This demo demuxes the AVIF container with avif_1 and decodes the AV1 payload with libaom_1 — the same decoder used for the AV1 video demo below.

Code snippet

<img is="universal-img_1" src="example.avif" using="solver_1"
     with="avif_1;libaom_1"> </img>

Specifications :

The specifications of the test sequence are :

Format AVIF
FileSize 111 Ko
Solver solver_1
