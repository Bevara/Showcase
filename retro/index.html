Display Amiga and Atari pictures using the <img> tag

RECOIL decodes several hundred picture formats from 8 and 16-bit machines. Three are shown here: an Amiga IFF/ILBM file with its interleaved bitplanes, an Atari ST Degas PI1 file with its 3-bit-per-channel ST palette, and a Microsoft Paint 1.0 MSP bitmap — not a retro computer format, but nothing else in the player decodes it. Decoded here with librecoil_1

Code snippet

<img is="universal-img_1" src="testcard_uncompressed.iff" using="mm_solver_minimal_1.0.1"
     with="librecoil_1"> </img>
<img is="universal-img_1" src="testcard.pi1" using="mm_solver_minimal_1.0.1"
     with="librecoil_1"> </img>
