Display simple bitmap formats using the <img> tag

Five formats that predate modern compression and are still met daily: ZSoft PCX, Truevision TGA, SGI/RGB, the Netpbm family (PBM/PGM/PPM) and the X11 bitmap. Each is a header plus raw samples or a byte-oriented run-length scheme, so this filter carries its own decoders rather than a third-party library. Decoded here with simpleimg_1

Code snippet

<img is="universal-img_1" src="testcard.pcx" using="solver_minimal_1"
     with="simpleimg_1"> </img>
<img is="universal-img_1" src="testcard.tga" using="solver_minimal_1"
     with="simpleimg_1"> </img>
<img is="universal-img_1" src="testcard.sgi" using="solver_minimal_1"
     with="simpleimg_1"> </img>
<img is="universal-img_1" src="testcard.ppm" using="solver_minimal_1"
     with="simpleimg_1"> </img>
<img is="universal-img_1" src="testcard.xbm" using="solver_minimal_1"
     with="simpleimg_1"> </img>
