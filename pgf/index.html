Display PGF images using the <img> tag

PGF (Progressive Graphics File) is a wavelet codec designed to beat JPEG 2000 on speed at comparable quality, with progressive decoding built in. Shown lossless and at quality 4. Decoded here with libpgf_1

Code snippet

<img is="universal-img_1" src="testcard_lossless.pgf" using="solver_minimal_1"
     with="libpgf_1"> </img>
<img is="universal-img_1" src="testcard_q4.pgf" using="solver_minimal_1"
     with="libpgf_1"> </img>
