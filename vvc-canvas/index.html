Decode VVC video (MP4) using the <canvas> tag

Same VVC/MP4 source as the video tag version, but rendered directly to a <canvas> instead of being re-encoded to H.264. No encoder is needed in the chain.

Code snippet

<canvas is="universal-canvas_1" data-url="NovosobornayaSquare_640x360.mp4" using="solver_1"
     with="libOpenVVC_1;isobmff_1"> </canvas>

Specifications :

The specifications of the test sequence are :

Format MP4 (VVC, video only)
Resolution 640x360
FileSize 627 Ko
Solver solver_1
