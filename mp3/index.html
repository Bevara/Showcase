Play MP3 audio using the <audio> tag

MP3 decoding here uses the mpg123 engine compiled to WebAssembly (libmpg123_1), independent of whatever MP3 support (or licensing constraints) the host browser or platform has.

Code snippet

<audio is="universal-audio_1" src="ff-16b-1c-44100hz.mp3" using="solver_minimal_1"
        with="libmpg123_1" controls> </audio>

Specifications :

The specifications of the test sequence are :

Format MP3
FileSize 1.4 Mo
Solver solver_minimal_1
