Decode AVS3 video using the <video> tag

AVS3 is the current Chinese national standard, contemporary with AV1 and VVC. Like AVS2 it arrives as a raw elementary stream, decoded here by libuavs3d_1 and re-encoded to MP4 by libx264_1 and isobmff_1 for the <video> element. Note that the clip plays for well under a second: the file holds 600 picture start codes but only 10 frames come out of it. That is the file, not the filter — uavs3d's own uavs3dec, built natively from the same sources, decodes exactly the same 10 frames and then stops.

Code snippet

<video is="universal-video_1" src="SFTI_640x360.avs3" using="solver_1"
        with="libuavs3d_1;isobmff_1;libx264_1" controls> </video>
