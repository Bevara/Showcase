Display Photoshop documents using the <img> tag

A PSD file stores its layers plus, when saved with “Maximize Compatibility”, a flattened copy of the finished image. That merged image is what is decoded here, out of a PackBits-compressed document. Decoded here with libpsd_1

Code snippet

<img is="universal-img_1" src="testcard_rle.psd" using="solver_minimal_1"
     with="libpsd_1"> </img>

Specifications :

The specifications of the test sequence are :

Format PSD, 256×256, RGB 8-bit, PackBits
FileSize 195 Ko
Solver solver_minimal_1
