Display JPEG-LS images using the <img> tag

JPEG-LS (ISO/IEC 14495-1) is the lossless and near-lossless still image standard built on the LOCO-I predictor. It is widely used in medical imaging, where re-encoding losses are not acceptable. Decoded here with libcharls_1

Code snippet

<img is="universal-img_1" src="banny_hp0.jls" using="solver_1"
     with="libcharls_1"> </img>
