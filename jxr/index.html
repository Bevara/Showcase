Display JPEG XR images using the <img> tag

JPEG XR (ITU-T T.832), which Microsoft shipped as HD Photo, is a wavelet-free transform codec offering lossless and high-dynamic-range coding. Two files are shown: a lossless one, which decodes back to the encoder's input byte for byte, and the same picture at quality 0.6. Decoded here with libjxr_1

Code snippet

<img is="universal-img_1" src="testcard.jxr" using="solver_minimal_1"
     with="libjxr_1"> </img>
<img is="universal-img_1" src="testcard_lossy_q06.jxr" using="solver_minimal_1"
     with="libjxr_1"> </img>
