Render PDF documents using the <img> tag

This demo renders the first page of a PDF document to a raster image directly in the browser, usingthe poppler PDF rendering library (libpoppler_1).

Code snippet

<img is="universal-img_1" src="minimal-document.pdf" using="solver_minimal_1"
     with="libpoppler_1" out="rgb"> </img>

Specifications :

The specifications of the test sequence are :

Format PDF (page 0)
FileSize 82 Ko
Solver solver_minimal_1
