Display BPG images using the <img> tag

BPG (Better Portable Graphics) was proposed as a royalty-bearing-free JPEG replacement built on HEVC intra compression, offering much better compression at equivalent quality. No browser ever adopted it natively. Decoded here with libbpg_1.

Code snippet

<img is="universal-img_1" src="photo.bpg" using="solver_minimal_1"
     with="libbpg_1"> </img>
