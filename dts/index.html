Play DTS audio using the <audio> tag

DTS Coherent Acoustics is the surround codec of cinema and Blu-ray discs; no browser decodes it. This one goes through libdca_1, built on dcadec - a standalone DTS decoder, not an ffmpeg wrapper.

Code snippet

<audio is="universal-audio_1" src="ff-16b-2c-48000hz.dts" using="solver_minimal_1"
     with="libdca_1" controls> </audio>
