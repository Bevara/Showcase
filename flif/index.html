Display FLIF images using the <img> tag

FLIF (Free Lossless Image Format) is a lossless format built on MANIAC entropy coding, whose bitstream is fully progressive: any prefix of the file already decodes to a complete image. Decoded here with libflif_1

Code snippet

<img is="universal-img_1" src="testcard.flif" using="solver_minimal_1"
     with="libflif_1"> </img>
