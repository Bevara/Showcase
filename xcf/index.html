Display GIMP documents using the <img> tag

XCF is GIMP's native format: a canvas plus a stack of layers, each stored as tiles. The filter composites the visible layers onto the canvas and hands over the result. Decoded here with libxcf_1

Code snippet

<img is="universal-img_1" src="testcard_rle.xcf" using="solver_minimal_1"
     with="libxcf_1"> </img>
