Play Musepack audio using the <audio> tag

Musepack is a lossy codec derived from MPEG-1 Layer 2, tuned for transparency at high bitrates rather than for low ones. Decoded with libmpc_1 (libmpcdec, stream versions 7 and 8).

Code snippet

<audio is="universal-audio_1" src="ff-16b-2c-44100hz.mpc" using="solver_minimal_1"
     with="libmpc_1" controls> </audio>

Specifications :

The specifications of the test sequence are :

Format Musepack SV8
Audio 16-bit stereo, 44.1 kHz
FileSize 144 Ko
