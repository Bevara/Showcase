Play XVID video (AVI) using the <canvas> tag

XVID/DivX was the dominant way to distribute compressed video before browsers gained native H.264 support, and AVI/XVID files are still unplayable in any modern browser. This demo demuxes the AVI container with avidmx_1, decodes the XVID video stream with libxvid_1, and the MP3 audio stream with libmad_1.

Code snippet

<canvas is="universal-canvas_1" data-url="https://download.blender.org/durian/trailer/Sintel_Trailer.480p.DivX_Home_Theater.divx" using="solver_1"
     with="avidmx_1;libxvid_1;libmad_1"> </canvas>

Specifications :

The specifications of the test sequence are :

Format AVI
Video XVID
Audio MP3
Solver solver_1

Only available as a canvas demo for now: re-encoding this decoder's output to MP4 via the <video> tag currently fails to connect to the H.264 encoder (a pixel-format mismatch between libxvid_1's output and the encoder input, unrelated to the encoder itself).
