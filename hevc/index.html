Decode HEVC video (MP4) using the <video> tag

HEVC/H.265 offers roughly double the compression efficiency of H.264 but carries licensing costs that keep many browsers from supporting it natively. This demo demuxes the MP4 container with isobmff_1 and decodes the HEVC stream with libde265_1;libfaad_1.

This pipeline re-encodes the decoded frames to MP4 through an H.264 encoder filter (ffmpeg-x264_1), matching exactly how this decoder is exercised in the project's own automated test suite. That encoder negotiation step is not fully reliable in every browser/GPAC build combination yet, so playback may not render everywhere — this demo still exercises the full demux + decode chain end to end.

Code snippet

<video is="universal-video_1" src="hevcds_720p30_2M.mp4" using="solver_minimal_1"
     with="libde265_1;libfaad_1;isobmff_1;ffmpeg-x264_1" controls> </video>
