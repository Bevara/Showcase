Decode Ut Video using the <video> tag

Ut Video is a fast lossless intra codec, met mostly inside AVI files coming out of capture and editing software. It has no container of its own, so this is a four-filter chain rather than three: avidmx_1 parses the AVI and emits a pid whose codec id is the Ut Video fourcc, libutvideo_1 decodes it, and libx264_1 with isobmff_1 produce the MP4 the <video> element plays. All 50 frames come out; because the codec is lossless, the reference is ffmpeg's own decoder, which reproduces the source frames byte for byte.

Code snippet

<video is="universal-video_1" src="testcard.avi" using="solver_1"
        with="avidmx_1;libutvideo_1;isobmff_1;libx264_1" controls> </video>

Specifications :

The specifications of the test sequence are :

Format Ut Video ULY0 (lossless 4:2:0) in AVI, 320x180, 25 fps, 50 frames
FileSize 639 Ko
Solver solver_1
